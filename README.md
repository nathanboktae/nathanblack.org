# Centipede Homepage

A silly personal homepage arcade game inspired by Atari Centipede.

Three centipedes start on the board. Clear one completely to jump to Nathan's
LinkedIn, Instagram, or GitHub profile. Losing plays the Edge of Tomorrow GIF
and restarts the game.

## Development

```sh
pnpm install
pnpm run dev
```

## Build

```sh
pnpm run build
```
